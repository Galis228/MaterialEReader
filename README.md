# Material eReader

Удобная читалка книг для Android в стиле Material You.

- EPUB, FB2, FB2.zip, MOBI, TXT, PDF (на Android 15+ и как текст), комиксы и манга CBZ/CBR/CB7 и папки картинок
- Манга: справа налево, по кадрам, лента-вебтун, развороты, обрезка полей, следующий том сам
- Прокрутка или страницы с анимациями перелистывания (сдвиг, наложение, затухание, рулон), разворот в альбомной ориентации
- Темы «Бумага», светлая, тёмная, OLED-ночь; Material 3 с цветами из обоев или обложки
- ИИ-помощник: объяснения, карта персонажей, хронология, поиск по смыслу; все результаты сохраняются
- Полки, выбор нескольких книг, 29 достижений с уровнями
- Закладки, оглавление, прогресс с отметками глав, время до конца главы
- Автопоиск книг в выбранных папках, каталоги OPDS
- Автообновление из GitHub Releases

## Шрифты

Встроенные шрифты (Literata, PT Serif, PT Sans, Lora, EB Garamond, Fira Sans, Andika) распространяются по лицензии SIL Open Font License 1.1 — тексты лицензий в папке `fonts-licenses`.
