## Material eReader 0.4.0

**Новое**
- ИИ по API: свой ключ для OpenAI-совместимых сервисов (OpenAI, OpenRouter, DeepSeek, Groq, LM Studio), Gemini и Claude. Ответы приходят по мере генерации, ключ хранится зашифрованным, есть кнопка «Проверить»
- Поиск по тексту книги с фрагментами и переходом к найденному месту
- Выделения и заметки: долгое нажатие на абзац — цвет маркера, заметка, копирование, «Спросить ИИ про этот абзац»
- Вкладка «Цитаты» в оглавлении и экспорт всех выделений книги в Markdown
- Яркость и тёплый фильтр прямо в настройках текста

В режиме API фрагменты книги отправляются выбранному сервису; все остальные режимы ИИ работают офлайн.
