## Material eReader 0.10.0

**Material 3**
- Цвета приложения из обоев (Material You), из обложки последней книги или классические зелёные; светлая, тёмная или как в системе; чёрный фон для OLED
- Скругления, плавные переходы между экранами, жест «назад» с предпросмотром, заставка Android 12+ в цветах приложения

**Библиотека**
- Два вида на выбор (Настройки → Библиотека): вкладки-полки или полки рядами, как в магазине
- Выбор нескольких книг: на полку, прочитано, скрыть, удалить — разом
- Полка серии или автора в один тап из меню книги
- «Добавить» → «Папка с мангой»: папка картинок становится томом, папка глав — серией

**Настройки** — разложены по разделам: Оформление, Библиотека, Чтение и перевод, ИИ-помощник, Данные, О приложении

**ИИ-помощник**
- Новое меню-плитки: «Эта страница», «Книга до этого места», «Для себя» и строка «Спросить о книге…»
- Глубина объяснений: как ребёнку, просто, подробно, академично
- «Результаты ИИ»: обложки книг → страница книги по разделам → результат с закреплением, «Поделиться» и переходом к месту
- Карта персонажей в трёх видах: Фокус, Семьи (ИИ сам делит героев на семьи и стороны), Список с поиском
- Поиск по смыслу во всей библиотеке, читательский профиль, мои цитаты по темам

**Достижения** — 29 штук, у многих бронза, серебро и золото; уведомление при получении; лента «История чтения» по дням в статистике

**Комиксы и манга**
- Режимы: страницы, по кадрам (камера сама переходит от кадра к кадру), лента для вебтунов
- Разворот из двух страниц в альбомной, обрезка полей, больше контраста для бледных сканов
- В конце тома — сразу следующий том серии
- Архивы 7z (CB7); тома распознаются по названию: «Vol. 3», «том 12», «ch 105»
- PDF на Android 15+: «Читать как текст» делает текстовую копию с переносом строк

**Убрано** — режим повторения слов
